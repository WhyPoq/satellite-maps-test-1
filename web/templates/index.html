About this implementation

Based on Poullis & You, Delineation and geometric modeling of road networks (2010), §4. The existing code uses 2×2 tensors, steerable FFT voting, and stick-only votes. This approximates the paper’s 3D tensor formulation and decay field.

σ = 12, angular order = 8, and frequency bounds 0.05–0.4 are implementation choices. Curves dominate where curve saliency exceeds junction saliency. Ridge extraction adds non-maximum suppression and the existing 0.1% numerical floor. Outputs are feature candidates, not segmented roads.

Segmentation prototype limits

Segmentation uses one diagonal Gaussian per class and a weighted Potts energy with α-expansion. The paper uses GMMs with MDL model selection and different orientation-aware data and smoothness terms (Eqs. 11–16). Road/background seeds are supplied manually as in the paper.

Orientation confidence is normalized curve saliency restricted to the classified ridges. Mask quality depends on the examples you mark. Orientation output is quantized; iteration limits can stop the solver before convergence.

Network extraction notes

Automatic extraction uses the supplied centreline filters, weighted Hough transform, tracking, and polygon union. Stage 1 curve evidence is available in this pipeline; mask boundaries reproduce the standalone script’s input choice.

JSON and GeoJSON use image pixel coordinates, not geographic coordinates. The optional manual refinement actions in the script remain available through its CLI. Defaults and filter assumptions are documented in the README.
